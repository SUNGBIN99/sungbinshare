投稿须知

欢迎投稿！请先了解各板块规则，管理员审核通过后展示

🍬 糖点分享

  • 请基于真实物料分析，标注出处与时间
  • 🚫 不嗑队友、🚫 不血糖、🚫 不无厘头延伸
  • 投稿后由管理员审核，确认无误再上线

📖 精品同人 / 产出太太

  • 本站仅收录「链接 + 作者账号」，请去原平台支持
  • 推荐前请确认作者允许被推荐 / 转载
  • 产出太太请填写类型（写文 / 画图 / 剪辑）与主页

🎬 视频分享

  • 提供平台链接即可，不私自搬运视频
  • 作者自行上传需提供「自证」（证明是本人）
  • 获得授权的内容可站内播放，否则仅外链

📷 双人照片

  • 分类：官图 / 站姐饭拍 / 画手产出，需标注图源
  • 站姐图、饭拍图须在获得拍摄者授权后上传
  • 画手产出须注明画手昵称

审核流程

提交 → 管理员查收 → 核对规则与授权 → 通过展示 / 退回说明。审核周期一般为 1–3 天。
